## 功能

- **搜索**：按 `/` 聚焦搜索框，`Esc` 清空。跨三个视图生效。
- **标记**：点条目右侧的 ○ 标记为「未掌握」，存在浏览器本地，刷新不丢。
- **导出错题本**：把所有标记条目导出为 Markdown 文件。
- **打印**：`Ctrl/Cmd + P` 可存为 PDF，导航与按钮会自动隐藏。

## 结构

单文件，三段：

```
<style>      设计系统（CSS 变量、各学科主色）
<body>       骨架（侧栏 + 顶部控件 + 主体容器）
<script>
  const SUB = [...]   ← 所有内容都在这里
  const FIG = {...}   ← SVG 图库（12 张）
  render() / filter() ← 渲染与筛选
```

外部依赖只有两个 CDN：KaTeX（公式渲染）和 Google Fonts（IBM Plex）。断网时公式会退化为源码，其余功能正常。

## 数据结构

一个学科是 `SUB` 数组里的一项：

```js
{
  k: "gm",                    // 唯一 key，也用于配色选择器 body[data-sub="gm"]
  name: "高等数学",
  en: "CALCULUS",
  no: "1",                    // 可选，侧栏显示的课程编号
  eqLabel: "公式速查",         // 可选，第二个视图的名字（默认「公式速查」）
  flLabel: "解题流程",         // 可选，第三个视图的名字（默认「解题流程」）
  lede: "导语，支持 <strong> 等标签",
  M: [ ...章节... ],
  F: [ ...流程... ]
}
```

### 章节 `M[i]`

```js
{
  t: "章节名",
  sub: "章节副标题",
  fig: "wuxing",              // 可选，挂载 FIG 里的图；多张写成 ["a","b"]
  map: [                      // 知识图谱视图：分支树
    ["分支名", "末梢1；末梢2；末梢3"]   // 第二项按「；」自动拆成末梢标签
  ],
  spine: "本章的主脉句（绿色斜体那句）",
  g: [                        // 速查视图：分组条目
    { g: "分组名", r: [
        ["条目名", "小字条件", "内容（可含 $LaTeX$）", "可选的黄色陷阱提示"]
    ]}
  ]
}
```

### 流程 `F[i]`

```js
{
  t: "流程名",
  when: "什么时候用",
  s: [                        // 步骤
    {
      b: "步骤名",
      p: "说明",
      f: [["条件","做法"], ...],   // 可选，灰色分支行
      trap: "可选，黄色警示"
    }
  ]
}
```

## 常见修改

**改一条内容**：在 `SUB` 里搜索该条目的文字，直接改。

**加一个章节**：往对应学科的 `M` 数组里加一项，字段照上面的结构填。

**加一门学科**：
1. 往 `SUB` 数组加一项。
2. 在 `<style>` 里加两条配色：
   ```css
   body[data-sub="xx"]{--accent:#RRGGBB}
   body[data-sub="xx"] .spine{color:#RRGGBB;background:#淡色}
   ```

**加一张图**：在 `FIG` 对象里加一个返回 SVG 字符串的函数，然后在章节里写 `fig: "函数名"`。可用的颜色变量：`A`(主色) `I`/`I2`/`I3`(文字三级) `R`/`RU`(边框) `C`(卡片底)。

**LaTeX 注意**：数学模式里不能出现裸的中文，要用 `\text{中文}` 包起来，否则 KaTeX 会告警。

## 校验

改完内容后建议跑一次结构校验（需要 Node）：

```bash
node check.js
```

会检查：数据能否正常解析、各学科条目数、数学模式里有无裸中文。

## 已知问题

- 单文件 360KB，`git diff` 时数据段的改动比较难读。若后续内容继续增长，可考虑把 `SUB` 拆到独立的 `data.js`。
- 内容为教材知识梳理，中医与倪师课程部分不构成任何诊疗或用药建议。
